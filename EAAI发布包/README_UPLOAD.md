# EAAI 历史投稿材料

本目录为 Engineering Applications of Artificial Intelligence 的早期研究版本，使用 square、circle、butterfly 路径；与当前 ESWA、KBS、JIM 的 long/dense 研究稿分别保存。

文件最终核验日期为2026-10-07。正文18页，本轮仅修复表格排版和编译依赖，保留原科学内容及结果；作者页邮箱和Highlights已校正。

| 用途 | 文件 |
| --- | --- |
| 匿名正文 | 01_manuscript_without_author_details/manuscript_without_author_details.pdf |
| 作者页 | 02_title_page_with_author_details/Title Page with Author Details.docx |
| 历史投稿信 | 03_cover_letter/cover letter.docx |
| 图件 | 05_figures；图号对应见 figure_mapping.md |
| 自包含正文源码 | 06_latex_source_files/latex_source_files_anonymous.zip |
| Highlights | 07_highlights/Highlights.docx |

源码ZIP解压后，在 latex_source_anonymous 中运行 build.ps1；输出为 _build/manuscript.pdf。需已有 XeLaTeX 和 BibTeX，并将其安装目录加入 PATH。

完整本地交付包为本目录内的 EAAI发布包.zip。解压后按投稿系统文件类别选择材料，完整交付包包含署名附件，不能作为匿名正文附件整体上传。当前 ESWA 修订终稿位于相邻 ESWA发布包，请匹配各版本的正文和源码。
