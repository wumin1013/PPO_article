版本日期：2026-01-06  
面向：RCIM 投稿 + 可复现 Artifact（代码/数据/图表一键生成）

---

## 1) 总目标（系统层面）
在轮廓误差容许带（tolerance band，±ε/2）约束下学习策略 π，使其在不同轨迹族上同时满足：

- **直线段**：高进给、贴线（误差不超带）
- **拐角段（Arc-in-band · 内切圆弧）**：在允差带内自动选择一条**内切、圆弧平滑**的过渡轨迹（允许带内自由偏移，不强迫贴中心线），且满足  
  1) **切线连续（C1）**：进弯/出弯处方向连续，不出现“尖角/折线”；  
  2) **内切倾向**：对于孤立拐角，轨迹优先落在“拐角内侧半带”（inside half-band），在不越带前提下减少转向激烈程度；  
  3) **效率优先**：在满足误差与运动学约束下，**降速尽量少、过弯尽量快**。
- **全程**：到达终点、无停滞、运动学约束零违规（由 KCM/action shielding 保证或统计证明）

> 直白口径：拐角不需要“贴中线”，需要“在带内画一段更像圆弧的内切轨迹”，这样才能少刹车、少抖、过弯更快。

---

## 1.1 关键定义（避免目标误解）
- **允差带 = 约束/可行域**：拐角段把 `contour_error` 当作“是否越带”的判据；**带内误差不作为主要惩罚目标**（只要 `|e_n| ≤ ε/2` 即合格）。
- **内切（inside）**：对“孤立拐角”（非 S 型复合弯），定义 `turn_sign ∈ {-1, +1}`（左转为 +1，右转为 -1），则  
  `inside = (turn_sign * e_n) ≥ 0`（按约定 e_n：左正右负）。  
  > 如果 inside 经常为负，说明策略在“反方向偏离”，这通常不是“学歪了”，而是几何符号/口径不一致导致的系统性错误。
- **尖角（cusp）**：拐角附近出现“方向/曲率突变”，表现为轨迹呈折线、`|omega|` 或 `|angular_acc|` 出现尖峰、或由点列估计的曲率 κ 出现极大值。
- **效率**：`steps` / `cycle_time` 不劣于 baseline_ref 的容忍比例（建议 ≤ 1.05×）；并对拐角窗口统计 `v_drop_ratio`（或等价指标）。
- **硬约束**：kcm_violation_rate = 0（或机制保证 + 明确说明）

---

## 2) 必须项（Paper-level Gate）
每个 PhaseB run 必须同时满足：

1) **到达终点**：reached_target = true  
2) **不越带**：max_abs_e_n ≤ ε/2（或 trace 证明带外步数为 0 / 可接受阈值）  
3) **效率不退化**：steps ≤ 1.05× baseline（阈值可在主表固定）  
4) **硬约束零违规**：kcm_violation_rate = 0（或统计为 0）  
5) **不允许“反向偏离”系统性存在**：对孤立拐角，inside_ratio（见 3.2）应明显 > 0.5（建议 ≥ 0.6），否则先修口径/符号再训练

## 3) 改善项（至少满足 1 条，才算“进步”）
### 3.1 平滑性（核心）
- **拐角平滑性**：corner_mask 段 `peak(|omega|)`, `p95(|angular_acc|)` 或 `p95(curvature_kappa)` 显著下降
- **尖角消失**：corner_sharpness_index 显著下降（见 3.2 的 κ 指标）

### 3.2 内切圆弧化（几何层面）
- **内侧占比**：`inside_ratio = mean( turn_sign*e_n ≥ 0 )`（仅对孤立拐角统计）
- **内侧深度**：`inside_depth = mean( clamp(turn_sign*e_n, 0, ε/2) ) / (ε/2)`（0~1）
- **圆弧化**：在 corner_mask 点列上估计曲率 `κ≈Δθ/Δs`，用 `p95(κ)` 或 `max(κ)` 作为“尖角指数”（越小越圆）

### 3.3 降速更少 / 过弯更快（效率层面）
- **降速更少**：corner_mask 段 `min(v)` 更高 / `v_drop_ratio` 更高
- **出弯回线更快**：corner_end 后固定窗口内 e_n 收敛更快、带外步数减少
- **直线不退化**：non-corner 段 mean(v) 更高，且贴线不退化

## 4) 证据链（必须能从产物自动计算出来）
为保证“可计算、可复现、可对比”，每个 Run Bundle 必须包含：
- `summary.json`：必须项 + 改善项（含 inside_ratio / curvature_kappa_p95 / corner_sharpness_index）
- `trace.csv`：至少包含 e_n, v, omega, angular_acc（或可推导）与 corner_mask/corridor_active
- `overlay.png`：拐角附近放大图（baseline vs 当前 run）
- `main_table.csv`：每 run 自动追加一行（含上述关键指标）
