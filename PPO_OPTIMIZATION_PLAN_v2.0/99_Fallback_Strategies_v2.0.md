# v2.0 备选方案与降级策略
版本日期：2026-01-17

---

## 0) 概述

v2.0 极简路线基于假设"效率压力驱动平滑"。如果假设不成立，需要备选方案。

本文档定义：
1. 各阶段的降级策略
2. 备选方案的优先级
3. 最终兜底方案

---

## 1) Phase 30 降级策略

### 1.1 预期结果

| 指标 | 理想 | 可接受 | 需降级 |
|------|------|--------|--------|
| success_rate | ≥0.98 | ≥0.95 | <0.95 |
| max_abs_e_n | ≤0.6 | ≤0.75 | >0.75 |
| corner_peak_ω | <0.8×MAX | <0.95×MAX | ≈MAX |
| steps | ≤1.1×baseline | ≤1.2×baseline | >1.5×baseline |

### 1.2 降级选项

#### 选项 A：增强效率压力

```yaml
reward_weights:
  p4:
    time_penalty: -0.05  # 从 -0.02 增强到 -0.05
```

**何时使用**：corner_peak_ω 接近 MAX，但 success_rate 高

**原理**：更强的时间惩罚 → 更大的效率压力 → 策略更"怕慢"

#### 选项 B：延长训练

```yaml
training:
  num_episodes: 500  # 从 200 增加到 500
```

**何时使用**：指标有改善趋势但未收敛

#### 选项 C：调整 boundary

```yaml
reward_weights:
  boundary:
    mode: soft
    soft_margin: 0.7  # 从边界的 70% 开始渐进惩罚
```

**何时使用**：策略过于保守，远离边界导致效率低

#### 选项 D：进入 Phase 31

**何时使用**：A/B/C 都尝试后仍无改善

## 2) Phase 31 降级策略

### 2.1 如果曲率状态无效

**症状**：加入曲率状态后 corner_peak_ω 仍无下降

**选项 E：轻量曲率惩罚**

```yaml
reward_weights:
  curvature_penalty:
    enabled: true
    weight: 0.001  # 极小权重
```

```python
# 在 reward.py 中
r_curvature = -w_curv * abs(dkappa_ds_norm)
```

**注意**：这仍然是极简的（只加 1 个参数），比 v1.9 的 15+ 参数简单得多。

### 2.2 如果轻量曲率惩罚也无效

**选项 F：中等曲率惩罚**

```yaml
curvature_penalty:
  weight: 0.01  # 增加 10 倍
```

## 3) 最终兜底方案

如果所有 v2.0 方案都失败，考虑：

### 选项 G：混合方案

从 v1.9 的 B2a 中选择**最少必要的**规则：

```yaml
reward_weights:
  minimal_mode: true
  w_s: 20.0
  
  # 只保留 1-2 个最关键的规则
  corridor:
    enabled: true
    dir_pref_weight: 1.0  # 只保留内切偏好
    # 其他全部禁用
```

**原则**：尽可能少的规则，每加一个都要有明确理由

### 选项 H：承认限制

如果无法实现"完全端到端"，论文叙事调整为：

> "实验表明，纯端到端学习在本任务中难以涌现平滑行为。通过引入极轻量的曲率连续性约束（单一参数），策略成功学习了平滑过渡策略。这表明，适度的领域知识引入可以显著加速强化学习的收敛，同时保持方法的简洁性。"

这仍然是有价值的科研贡献（比"需要 15 个参数"强得多）。

## 5) 各方案的论文叙事

### 最佳情况：Phase 30 成功

> "我们采用极简奖励设计（仅包含进度激励和效率惩罚），策略在没有任何显式几何规则的情况下，自主学习了拐角平滑过渡策略。这验证了强化学习在运动规划任务中的端到端学习能力。"

**亮点**：完全端到端，无规则引导

### 次佳情况：Phase 31 成功

> "为帮助策略感知轨迹形状，我们在状态空间中加入了曲率特征。实验表明，这种状态扩展使策略能够更高效地学习平滑行为，同时保持端到端学习的特性（无显式控制规则）。"

**亮点**：端到端学习，状态增强

### 可接受情况：选项 E/F 成功

> "我们发现，纯端到端学习在本任务中收敛较慢。通过引入极轻量的曲率连续性惩罚（单一参数 λ=0.001），策略的平滑性显著提升。相比传统多参数 reward shaping 方法，我们的设计保持了简洁性和可解释性。"

**亮点**：简洁设计，单参数调优

### 最后方案：选项 G/H

> "实验表明，完全端到端学习在本任务中面临挑战。我们提出的混合方法结合了极简奖励设计和最少必要的领域知识引入，在保持方法简洁性的同时实现了有效的轨迹平滑。"

**亮点**：务实的工程-学习平衡
