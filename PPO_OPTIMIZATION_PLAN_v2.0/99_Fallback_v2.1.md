### 1.2 降级选项

#### 选项 A：轻量曲率惩罚

```yaml
reward_weights:
  curvature_penalty:
    enabled: true
    weight: 0.001  # 极小权重
```

```python
r_curvature = -0.001 * abs(dkappa_ds_norm)
```

**原理**：直接惩罚曲率变化，单一参数，比 v1.9 的 15+ 参数简单得多。

#### 选项 B：增强效率压力

```yaml
p4:
  time_penalty: -0.05  # 从 -0.02 增加
```

**注意**：这在 v2.0 已证明效果有限，仅作为辅助手段。
