# 工作流程（v3.0）
版本日期：2026-01-18

---

## 执行顺序

```
Phase 30: 前瞻+管道基线 → Phase 32: 多路径验证 → Phase 33: 消融分析 → Phase 40: 论文
```

---

## Phase 30：前瞻+管道基线训练

### 输入
- P0_L2 基线模型
- 方形路径定义

### 输出
- 训练好的 v3.0 模型
- summary.json（含 corner_peak_ω, inside_ratio）

### 验收
- success_rate ≥ 0.95
- corner_peak_ω < 0.85 × MAX

---

## Phase 32：多路径验证

### 输入
- Phase 30 训练好的模型

### 测试路径
- 方形 (90°)
- 梯形 (60°, 120°)
- 圆形

### 验收
- 所有路径 success_rate ≥ 0.90
